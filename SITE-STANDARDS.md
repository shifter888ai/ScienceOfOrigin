# Site Standards

These are simple working conventions for keeping the Science of Origin website coherent. They are open to revision.

## Shared header and footer

- Use a consistent site identity, logo treatment and global header.
- Keep the main navigation consistent in labels, order and behavior; indicate the current page where appropriate.
- Use a consistent footer for project identity, status, copyright and shared links.
- Do not create page-specific redesigns of the global header or footer without a clear reason.
- When a shared element changes, consider all pages that use it and update them consistently.

## Page design

- Keep pages lightweight, readable, responsive and accessible.
- Prefer the existing shared stylesheet and established page patterns.
- Use clear page titles, headings and meaningful links.
- Let each page use the content structure it needs; consistency does not require identical layouts.
- Avoid unnecessary libraries, frameworks, dependencies and visual complexity.

## Content and navigation

- Give each page a clear purpose and avoid unnecessary duplication.
- Link related subjects and reference materials where useful.
- Keep links relative within the site where appropriate, and check links when moving or renaming files.
- Make the working or research status clear when it matters.

## Changes

Review shared elements across the site before changing them. Prefer small, reviewable pull requests. Do not merge or deploy without explicit approval.

These conventions describe the current direction, not permanent restrictions. Improve them when practical experience justifies it.

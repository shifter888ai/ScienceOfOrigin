# Science of Origin — Terminology Inventory

**Status:** Initial extraction register · Version 0.1  
**Purpose:** Comprehensive, source-traceable discovery register for terminology used across Science of Origin.  
**Scope of this pass:** Public research pages and core framework documents in the repository. This is an initial extraction, not yet a completeness claim. Historical Reddit, Weibo, Chinese compilation, and other original source collections remain a later extraction layer.

## 1. Purpose and governing rules

The inventory records terminology as it appears in source materials before attempting to standardize it. It is a research register, not a reader-facing dictionary and not a declaration that every recorded term is accepted, proven, or current.

- Preserve exact source forms, including capitalization, spelling, punctuation, language, and historical variants.
- Record the source and location for each occurrence or definition.
- Keep similar expressions separate until their equivalence is established.
- Do not silently merge, replace, correct, or discard terms.
- Do not invent a definition where the source does not provide one.
- Preserve obsolete, superseded, provisional, and disputed usage as part of terminology history.
- Distinguish source wording from later interpretation or editorial synthesis.
- Treat a working meaning as a description of current usage, not as proof of the claim it expresses.
- Keep private or restricted source material subject to the library's privacy and permissions rules.

## 2. Inventory record schema

Each term record should eventually include:

| Field | What to record |
|---|---|
| Term ID | Stable identifier, assigned without encoding a preferred interpretation |
| Preferred display term | Current preferred form, if one has been agreed |
| Exact source form | The exact expression as it appears in each source |
| Language / script | English, Traditional Chinese, Simplified Chinese, mixed, etc. |
| Variants | Spelling, capitalization, abbreviations, translations, historical forms |
| Category | Foundational, origination, existence, structure, dynamics, research method, application, evidence/status, or other |
| Source meaning | Definition or explanation explicitly supplied by the source |
| Context | Surrounding passage needed to interpret the usage |
| Distinctions | Terms the source distinguishes from this one |
| Relationships | Related terms and the stated nature of the relationship |
| Source location | File/page, section heading, and exact record or line where available |
| Usage period | Date/version/period, if known |
| Source status | Current page, working document, historical source, original record, etc. |
| Review status | Extracted, needs comparison, conceptually reviewed, agreed, or unresolved |
| Notes | Conflicts, ambiguity, translation issues, and questions |

No epistemic status is assigned merely because a term appears in a source. If a source explicitly labels a statement (for example, “observed understanding” or “research objective”), record that label verbatim and separately from our review status.

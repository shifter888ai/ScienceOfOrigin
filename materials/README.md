# Public Research Materials

This folder stores public source materials supplied for Science of Origin research and historical extraction.

Suggested organization:

- `wiki-chinese-qa/` — original Chinese Q&A records
- `reddit-english-qa/` — public English Reddit Q&A records

Please preserve original wording, dates, authorship, and source context. These files are source materials; extracted summaries and research interpretations should be kept separate from the originals.

**Visibility:** This repository is public. Files uploaded here are publicly accessible.

## Owner-confirmed monthly source archives

- `reddit-english-all.txt` and `reddit-english-qa.txt` are the project owner's complete, manually extracted and checked Reddit TXT archives for their intended collection scopes. Preserve them unchanged; add one new version monthly.
- `weibo-1760432301-combined-originals-2026-11-24T06-35-03-529Z.txt` is the project owner's complete, manually extracted and checked Weibo original-post TXT archive for its intended scope. Preserve it unchanged; add one new version monthly.
- `awakenology/` is a pinned Git submodule reference to the Awakenology repository. Its exact upstream commit and full file manifest are recorded in `library/coverage/awakenology-repository-snapshot-2026-11-25.md`. Update it monthly from upstream Git history.

The Reddit and Weibo TXT archives are complete according to the project owner's manual extraction and checks. Optional external media recovery and live-site crawling are separate layers, not conditions for declaring these supplied text archives complete.

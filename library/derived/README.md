# Derived research materials

Files in this directory are generated from source originals and must remain clearly distinguished from them. They do not replace or modify original source files.

## Chinese compilation OCR

- `chinese-image-page-ocr-2026-11-25.txt` and `chinese-image-page-ocr-2026-11-25.csv` are machine-generated Tesseract OCR outputs for the 206 PDF pages from which pypdf extracted no text.
- The OCR output is uncorrected and may contain recognition errors or noise. The CSV retains page numbers, OCR character counts, Han-character counts, and per-page output.
- Always compare OCR text with the original PDF page image before quoting or treating it as verified source text.
